# Proyectos

Esta carpeta contiene los proyectos desarrollados en **Programación Avanzada**, así como materiales de apoyo y ejemplos de semestres anteriores que puedan utilizarse como referencia académica.

## Contenido de un proyecto

Cada proyecto puede incluir:

- Descripción y contexto del problema.
- Objetivos.
- Requisitos funcionales y técnicos.
- Restricciones.
- Entregables.
- Criterios de evaluación.
- Fechas o etapas de entrega.
- Código inicial.
- Recursos de apoyo.
- Ejemplos o soluciones de referencia, cuando corresponda.

## Estructura sugerida

```text
proyectos/
├── README.md
```

## Uso de proyectos anteriores

Los trabajos de semestres anteriores se publicarán únicamente cuando exista autorización. Deben identificarse como material de referencia y no como una solución para copiar o reproducir.

Las soluciones oficiales o materiales reservados podrán mantenerse en repositorios privados o ramas de acceso restringido.
