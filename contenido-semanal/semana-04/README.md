# Ejercicios de Archivos de Texto y Archivos Binarios en C++

## Descripción

Proyecto académico desarrollado en C++ para practicar el manejo de archivos de texto y archivos binarios, estructuras, lectura y escritura de datos.

El proyecto contiene ejercicios resueltos y un documento de apoyo con los enunciados.

## Archivos

```text
.
├── ejercicios_archivos.cpp
└── Enunciados_Ejercicios_Binario_texto.pdf
```

* `ejercicios_archivos.cpp.`: contiene la solución de los ejercicios en un solo archivo.
* `Enunciados_Ejercicios_Binario_Texto.pdf`: versión en PDF de los enunciados.

## Compilación

Con `g++`:

```bash
g++ ejercicios_archivos. -o archivos
```

## Ejecución

En Linux o WSL:

```bash
./archivos
```

En Windows:

```bash
archivos.exe
```

## Conceptos utilizados

* Archivos de texto.
* Archivos binarios.
* ifstream.
* ofstream.
* fstream
* ios::binary.
* ios::app.
* Lectura con >>.
* Lectura con read().
* Escritura con write()
* Sobrescritura de archivos.


## Propósito

El proyecto tiene como objetivo reforzar los conceptos fundamentales del manejo de archivos en C++ mediante ejercicios prácticos y sencillos, utilizando estructuras, archivos de texto y archivos binarios.
