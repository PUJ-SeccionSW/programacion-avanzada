# Semana 03: Archivos de Tipo Texto - Acceso Secuencial

## Autoría

Las diapositivas de esta semana son de autoría del **profesor Jimmy Alejandro Castro Sabogal**.

## Temas

- Archivos: concepto, propósito y tipos.
- Archivos de tipo texto con acceso secuencial.
- Flujos (streams) y biblioteca `fstream`.
- Librerías estándar de C++.

## Resultados de aprendizaje

Al finalizar la semana, el estudiante estará en capacidad de:

- Explicar la diferencia entre archivos de texto y binarios, y sus métodos de acceso.
- Leer y escribir archivos de texto de forma secuencial usando `ifstream`, `ofstream` y `fstream`.
