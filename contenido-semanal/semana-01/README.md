# Semana 01: Estructuras y Tipos de Datos

## Temas

- Presentación del curso y objetivos.
- Revisión de conceptos de programación: estructuras y tipos de datos.
- Modificadores, tamaños y conversión entre variables.

## Resultados de aprendizaje

Al finalizar la semana, el estudiante estará en capacidad de:

- Reconocer los tipos de datos básicos, sus modificadores y tamaños en C++.
- Realizar conversiones entre variables de distintos tipos.
