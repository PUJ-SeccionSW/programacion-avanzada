# Contenido semanal

Esta carpeta organiza los materiales académicos de **Programación Avanzada** por semanas. La distribución podrá ajustarse de acuerdo con el calendario y la planeación de cada periodo académico.

## Organización

```text
contenido-semanal/
├── README.md
├── semana-01/
│   ├── README.md
│   ├── presentacion.pdf
│   ├── ejercicios.pdf
│   └── ejemplos-codigo/
├── semana-02/
└── ...
```

Cada carpeta semanal debe incluir un `README.md` con, al menos:

- Temas abordados.
- Objetivos o resultados de aprendizaje.
- Material de clase.
- Ejercicios o talleres, cuando correspondan.
- Ejemplos prácticos.
- Recursos complementarios y enlaces de interés.

No todas las semanas deben contener los mismos tipos de recursos. Su inclusión dependerá de los temas y actividades previstos.

## Plantilla para cada semana

```markdown
# Semana 01: nombre del tema

## Temas

- Tema principal.
- Tema complementario.

## Resultados de aprendizaje

Al finalizar la semana, el estudiante estará en capacidad de:

- Resultado de aprendizaje 1.
- Resultado de aprendizaje 2.

## Materiales

- [Presentación](presentacion.pdf)
- [Ejercicios](ejercicios.pdf)
- [Ejemplos de código](ejemplos-codigo/)

## Actividades

Descripción breve de las actividades previstas.

## Recursos complementarios

- [Nombre del recurso](https://ejemplo.com)
```
