# Ejercicios de Punteros en C++

## Descripción

Proyecto académico desarrollado en C++ para practicar el uso básico de punteros, arreglos, funciones y memoria dinámica.

El proyecto contiene ejercicios resueltos y un documento de apoyo con los enunciados.

## Archivos

```text
.
├── ejercicios_punteros.cpp
├── ejercicios_punteros_cpp.pdf
├── solucion-taller-apuntadores.cpp
└── taller_punteros.pdf
```

* `ejercicios_punteros.cpp`: contiene la solución de los ejercicios en un solo archivo.
* `ejercicios_punteros_cpp.pdf`: versión en PDF de los enunciados.
* `solucion-taller-apuntadores.cpp`: contiene la solución de las preguntas y ejercicios planteados en el taller.
* `taller_punteros.pdf`: contiene las preguntas y los enunciados de los ejercicios que se deben realizar.


## Compilación

Con `g++`:

```bash
g++ ejercicios_punteros.cpp -o ejercicios

g++ solucion-taller-apuntadores.cpp -o taller
```

## Ejecución

En Linux o WSL:

```bash
./ejercicios
-/taller
```

En Windows:

```bash
ejercicios.exe
taller.exe
```

## Conceptos utilizados

* Punteros.
* Direcciones de memoria.
* Desreferenciación.
* Arreglos.
* Aritmética de punteros.
* Funciones con punteros.
* Memoria dinámica.
* `new` y `delete[]`.
* Tipos `int` y `float`.

## Propósito

El proyecto tiene como objetivo reforzar los conceptos fundamentales de punteros mediante ejercicios prácticos y sencillos en C++.
