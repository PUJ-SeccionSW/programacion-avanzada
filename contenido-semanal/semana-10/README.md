# Ejercicios de Clases y Objetos en Java

## Descripción

Proyecto académico desarrollado en Java para practicar los conceptos fundamentales de la Programación Orientada a Objetos: clases, objetos, constructores, encapsulamiento, sobrecarga de métodos y miembros estáticos.

El proyecto contiene los ejercicios resueltos y un documento de apoyo con los enunciados.

## Archivos

```text
.
├── Pokemon.java
└── Ejercicios Clases y Objetos.pdf
```

* `Pokemon.java`: contiene la solución de los cuatro puntos en un solo archivo.
* `Ejercicios Clases y Objetos.pdf`: versión en PDF de los enunciados.

## Ejecución

En Linux, WSL o Windows:

```bash
java Pokemon.java
```

## Conceptos utilizados

* Clases y objetos.
* Constructores.
* La propiedad `this`.
* La notación punto (`.`).
* Atributos privados.
* Encapsulamiento con `get`, `set` e `is`.
* Métodos `private` como apoyo interno (`aplicarDano`).
* Constantes `static final`.
* Atributos y métodos `static`.
* Métodos de instancia y parámetros.
* Sobrecarga de métodos.
* Métodos `final`.
* Manipulación del estado de los objetos (daño, defensa, curación).

## Propósito

El proyecto tiene como objetivo reforzar los conceptos fundamentales de la Programación Orientada a Objetos en Java mediante un ejercicio práctico de combate entre objetos, aplicando encapsulamiento, sobrecarga y manejo de estado.
