# Ejercicios de Arreglos, Estructuras y Punteros en C++

## Descripción

Proyecto académico desarrollado en C++ para practicar el manejo de estructuras (`struct`), punteros, aritmética de punteros y  paso por referencia

El proyecto contiene ejercicios resueltos y un documento de apoyo con los enunciados.

## Archivos

```text
.
├──ejercicio_pilotos.cpp
└──Enunciados_Arreglos_Estructuras.pdf
```

* `ejercicio_pilotos.cpp`:Código fuente con la implementación completa y solución a los ejercicios.
* `Enunciados_Arreglos_Estructuras.pdf`: versión en PDF de los enunciados de los ejercicios.

## Compilación

Con `g++`:

```bash
g++ ejercicio_pilotos.cpp -o pilotos
```

## Ejecución

En Linux o WSL:

```bash
./pilotos
```

En Windows:

```bash
pilotos.exe
```

## Conceptos utilizados

* Estructuras (struct).

* Punteros y desreferenciación (*, ->).

* Aritmética de punteros ((pilotos + i)).

* Funciones y paso de parámetros por valor y por referencia (*&).


## Propósito

El proyecto tiene como objetivo reforzar los conceptos fundamentales relacionados con el uso de punteros hacia estructuras de datos, así como su manipulación.
