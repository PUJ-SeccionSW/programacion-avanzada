# Evaluaciones

Esta carpeta organiza las actividades utilizadas para valorar los resultados de aprendizaje de **Programación Avanzada**.

## Contenido

Puede incluir:

- Evaluaciones parciales.
- Talleres evaluables.
- Retos de programación.
- Rúbricas y criterios de calificación.
- Instrucciones de entrega.
- Recursos permitidos.
- Retroalimentaciones generales.

## Estructura sugerida

```text
evaluaciones/
├── README.md
├── evaluacion-01/
│   ├── README.md
│   ├── enunciado.pdf
│   └── rubrica.pdf
└── evaluacion-02/
    ├── README.md
    ├── enunciado.pdf
    └── rubrica.pdf
```

## Plantilla para cada evaluación

```markdown
# Evaluación 01: nombre de la actividad

## Propósito

Resultado o competencia que será evaluada.

## Instrucciones

1. Instrucción principal.
2. Condición de desarrollo o entrega.

## Entregables

- Archivo o evidencia requerida.
- Formato y medio de entrega.

## Criterios de evaluación

- Criterio 1 y ponderación.
- Criterio 2 y ponderación.

## Recursos permitidos

- Recurso permitido.
- Restricción aplicable.

## Fechas

- Apertura: por definir.
- Entrega: por definir.
```

## Acceso y confidencialidad

Los bancos de preguntas, soluciones, claves de respuesta y demás materiales reservados no deben publicarse en ramas abiertas. Cuando sea necesario, se almacenarán en repositorios privados o espacios con acceso restringido.

Antes de publicar una evaluación, se debe verificar que las instrucciones, los entregables, los criterios de calificación y las condiciones de presentación sean claros y consistentes.
